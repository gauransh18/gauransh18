## Apps

Each one started as something that annoyed me.

- 🎬 **[NotchPrompter](https://github.com/gauransh18/notchprompter)** — A teleprompter that lives in the Mac notch. Follows your voice with on-device speech, and stays out of your screen recording.
- 🪺 **[Perch](https://github.com/gauransh18/perch)** — Your coding agents, in the notch. Every session's tool feed live, approvals with a diff preview, what it cost, and a jump back to the exact terminal pane.
- 🪟 **[Spacebar](https://github.com/gauransh18/spacebar)** — Every macOS desktop at a glance, with live thumbnails of what's on them — including the Spaces you're not looking at.

All free, all open source, macOS 14+ → **[apps.gauranshsharma.com](https://apps.gauranshsharma.com)**

### Philosophy

> "Ship the fix, say plainly what it can't do, give it away." — I build for the annoyance first. If a feature can't work, the app says so instead of showing a button that lies.

<details>
<summary>How I build</summary>

- Swift + SwiftUI + AppKit. Menu-bar apps (`LSUIElement`), macOS 14+
- No Electron, no accounts, no telemetry, no network unless the network *is* the point
- Spike the risky API before committing a day to it — Spacebar started as a throwaway script proving Spaces could be enumerated, tagged, captured and switched, before any UI existed
- Everything is ad-hoc signed, so first launch needs right-click → Open. No Developer ID cert yet, and I'd rather say that than pretend

</details>
